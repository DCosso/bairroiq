# BairroIQ — Dicionário de Dados da Gold Distritos Wide

## Descrição

BairroIQ | Gold Distritos Wide. Snapshot analítico com uma linha por cada um dos 96 distritos administrativos oficiais do município de São Paulo. Consolida indicadores IBGE, GeoSampa, ObservaSampa, SSP-SP e mercado imobiliário. Cada fonte utiliza seu período mais recente disponível, que pode diferir entre os indicadores. Os dados imobiliários são agregados somente para bairros com associação territorial aprovada por proxy OSM. A tabela não possui histórico analítico nem colunas de data de referência. Valores NULL devem ser interpretados conforme o contrato de cada indicador, nunca como zero automaticamente.

## Contrato de dados

- **Tabela:** `workspace.gold.distritos_wide`
- **Granularidade:** uma linha por distrito oficial
- **Chave:** `CD_DIST`
- **Distritos esperados:** 96
- **Colunas esperadas:** 254
- **Temporalidade:** último valor disponível de cada fonte
- **Histórico analítico:** não disponibilizado na Gold
- **Localização imobiliária:** proxy OSM homologado

## Referência geográfica

- **Fonte:** IBGE — Malha Distrital 2022.
- **Arquivo versionado:** `barrioiq_pipeline/distritos_centroides_ibge_2022.json`.
- **Granularidade:** um centroide por distrito (`CD_DIST`), 96/96.
- **Cálculo:** geometria reprojetada para `EPSG:31983` e centroide convertido para `EPSG:4326`.
- **Campos:** `latitude` e `longitude`, tipo `DOUBLE`, oito casas decimais.
- **Limitação:** ponto representativo geométrico, não endereço, centro populacional ou polígono distrital.
- **Proveniência:** SHA256 do JSON `a0eea0fa2b80ec5565226f2982baae4699debc0f9baeb609d04cf817004333f8`.
- **Independência:** a referência geográfica é um JSON versionado, não uma sétima Silver.

## Ressalvas metodológicas

- O distrito administrativo não equivale necessariamente ao bairro imobiliário.
- Os indicadores podem ter referências temporais distintas.
- As métricas SSP representam registros classificados na fonte, e não necessariamente todos os eventos reais.
- O estoque imobiliário é uma soma de médias diárias dos anúncios ativos, não uma contagem de anúncios únicos durante o mês.
- Valores nulos não devem ser convertidos automaticamente em zero.
- Indicadores normalizados utilizam denominadores especificados em suas regras de cálculo.
